# Fux, note against note, in three and four parts

Johann Joseph Fux, *Gradus ad Parnassum* (Vienna, 1725): the first-species examples in three parts (Mann's figures
101–119) and four (160–172), in Humdrum `**kern`, copied unchanged from Mark Gotham's encoding of the *Gradus* —
[MarkGotham/species](https://github.com/MarkGotham/species) (commit `5c7cae4`, `II/sp1`, `III/sp1`), released by
Mark Gotham and FourScoreAndMore.org into the public domain (CC0 1.0), as each file's header says.

`tests/rules.mjs` reads them as the oracle of `@kairotic/rules`'s modal styles (`modal-2`, `modal-4`): each one's
lowest voice the bass, its upper voices judged.
