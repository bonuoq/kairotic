One line, from a note in a bar to a stroke in Hz and seconds, and the electronics wired to its notes Loading…

The line each axis has its own resolution, and it changes over time: draw it in the lanes below

Each axis glides on its own. Time: 0 where a note sounds (proportional) → 1 where it is written in a bar (on a grid of sixteenths, bar lines drawn). Pitch: 0 its exact frequency → ½ the nearest key (a semitone grid) → 1 its step on the staff, spelled in the key (an accidental where the signature does not say it). Glyph: 0 a stroke as thick as the note is loud, following its glissando → a head with a line as long as the note (proportional notation) → a note value with stem and flags, which needs metric time too. The lanes are drawn with the pointer; a preset begins them.

Wires a note of the line → an event of the electronics

Rigid: the electronics start on the note itself, however late; a note left out is caught up at the next one played. Elastic: they expect the note where the performer's tempo puts it (the last note played, shifted as it was); if the performer leads they wait for it up to the tolerance and then go on without it; if the electronics lead they start at that time and the performer follows.

About

Study 52. The first study of discussion #217. Notation as projections of one line of events at a resolution per axis — time, pitch, glyph — each free to change over time, so a phrase can begin on a staff, in bars, as note values, and dissolve into proportional notation and then into strokes in Hz and seconds, with the same data underneath: a continuous transition, not blocks side by side. And the synchronisation of live electronics drawn as wires from the notes to the events they start, rigid or elastic, with who leads. A follower that hears every note decides, wire by wire, when the electronics start; the kernel (kairotic/continuum.mjs, plain data in and out) is tested in Node and in the browser, and the same follower decides offline (what a simulated performer would get) and live (you, a key per note).

What it leaves open

  • A conditional wire: the electronics choose between branches and the performer's notation changes as they do.
  • Where a written note stops being exact: a value that is no value (1¼ beats) is drawn as the nearest one; ties are not written yet.
  • Verovio's engraving for the written end (its SVG keeps each note's id, which wires could anchor to).
