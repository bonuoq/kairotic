The boxes click one to add it

Each box is one element of Faust and one definition in the code. A loop must go through the one-sample delay ' (as gen~'s history): in code the network becomes a function of the delays' outputs fed back with ~. Several wires into one inlet are added. Numbers after a box's name fill its inlets the way Faust fills arguments: from the right for primitives (+ 0.5 is +(0.5)), in order for library functions (fi.lowpass 2 1000); a wired inlet takes the signal. Anything else typed in a box is Faust code kept as it is, with the inputs and outputs the compiler finds. In the other direction, code is read with Faust's block-diagram algebra (: , <: :> ~, infix operators, partial application, with, letrec); what the boxes do not know becomes a box of code, and code that cannot be read as boxes still compiles and plays, with the patch marked as out of date. The layout travels in the last comment of the code, so the code alone rebuilds the patch.
