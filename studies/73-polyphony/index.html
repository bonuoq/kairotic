About
The followers of discussion #308 hear a performer through
      pitch~ (YIN: one pitch at a time), onsets and descriptors such as the chroma — which folds every octave
      into twelve pitch classes. A piano, a guitar or an ensemble needs more. Basic Pitch (Spotify, 2022; Apache-2.0,
      code and weights) is a network of about 17,000 parameters that hears, 86 times a second, how likely each of the 88
      keys is to sound and to begin there: small enough to be fetched from jsDelivr and run here with ONNX Runtime
      Web, in a worker, on this machine — no sound leaves the page. This is the first use of discussion #137: one API for
      any model (kairotic/onnx.mjs: a session from a URL, kept in the browser's cache and checked by its hash;
      a run with arrays), and around it Basic Pitch's windows and its way of reading notes, ported
      (kairotic/basicpitch.mjs). The cadence is rendered here, so what was written is known: the notes
      found are scored against it, and each chord is heard against the same chord with one note an octave off — the
      keys tell them apart, a chroma cannot. A recording works too (record needs a page that may use the
      microphone, as Kairotic Pages). Next: the 88 keys as a descriptor the followers take (follow hmm notes),
      the profiles of a rehearsal with real pitches, and a take transcribed into a tree.
