      About this study
      
One buffer, two renderers. The strokes are a freqt buffer from kairotic/canvas.cljs, changed only through its events. The ink layer turns them into thi.ng/geom shapes and serializes them to SVG. The spectrum layer turns the same strokes, with the partials and rolloff of the view, into a texture drawn by a WebGL2 shader. Playback uses those same partials, so what you hear matches what the spectrum shows.

      
The library check lists each thi.ng/geom function the study uses and whether it worked in this browser.
