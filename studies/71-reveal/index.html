About
While a live-coding set is played the screen is only code (TOPLAP's
  show us your screens). Kairotic keeps every evaluation as an event of the history, with the time it was made, so
  when the set ends it can reveal what the code never showed: the patch it built, drawn by its flow (a layered
  drawing after Sugiyama: every box in a row after the boxes that feed it, the order in each row uncrossing the wires,
  each box under what feeds it; kairotic/layout.mjs), and the history on a time axis — every change a
  tick, every branch a row. The set can be played again from any point, at another speed, as it was, with its
  silences shortened (a pause of more than five seconds heard as five), or a step each change; and from
  another branch: a set is not a recording but a time that can be taken up again. A .kairotic file exported
  from the app opens here too (its main line).
