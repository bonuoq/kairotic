The recipe the same code, its sliders starting where the search found them

The recipe is code a faust~ box keeps: paste it in a box's code window, or run the call in the REPL ((code :b1 "…") writes it into box :b1). Nothing in the search is about one synth: any code with sliders can be looked for, and a slider called pitch (MIDI) or freq (Hz) is held where YIN hears the target's pitch, at the octave that sounds closest. Levels are compared apart from loudness (every render is brought to the target's loudest moment), so a recording at any level can be matched. The distance is Meyda's descriptors as features~ computes them (Studies 30–32).
