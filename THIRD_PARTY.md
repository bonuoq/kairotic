# Third-party code in the repository

*[Leer en castellano](THIRD_PARTY.es.md)*

Kairotic's own code is MPL-2.0. Code by others that Kairotic adapts, ports, bundles or compiles keeps **its own
licence**, when that licence is permissive (MIT, BSD, ISC, Zlib, Apache-2.0) or, inside the editor bundle, the
EPL: its files say so in their SPDX header (`MPL-2.0 AND MIT` when our code and theirs share a file), they are listed
here, and their notices are below. [`tests/spdx.mjs`](tests/spdx.mjs) fails on a header other than `MPL-2.0` that is
not listed here, and [`tests/licences.mjs`](tests/licences.mjs) on a published package that carries listed code
without declaring its licence and this file. Dependencies loaded from a CDN, never in the repository, are listed in
the [README](README.md#dependencies).

|---|---|---|---|
| `core/vendor/codemirror.mjs` | MPL-2.0 AND MIT AND EPL-2.0 AND ISC AND EPL-1.0 | the code editor bundle | CodeMirror 6 and Lezer (MIT), clojure-mode (EPL-2.0), lezer-clojure (ISC), squint (EPL-1.0): versions in `core/vendor/codemirror/package-lock.json` |
| `site/vendor/gun/` | MIT OR Zlib OR Apache-2.0 | rooms and saved works in Pages | [GUN](https://gun.eco), its licence in `site/vendor/gun/LICENSE.md` |
| `packages/spectral/assets/shift.mjs` | MPL-2.0 AND MIT | `shift~`'s WebAssembly | [stftPitchShift](https://github.com/jurihock/stftPitchShift) 2.0, compiled; generated by `packages/spectral/native/build.mjs` |
| `studies/28-shift/kairotic/shift.mjs` | MPL-2.0 AND MIT | the same module, for Study 28 | stftPitchShift, as above |
| `studies/29-live/kairotic/shift.mjs` | MPL-2.0 AND MIT | the same module, for Study 29 | stftPitchShift, as above |
| `studies/73-polyphony/kairotic/basicpitch.mjs` | Apache-2.0 | Basic Pitch's windows and note reading, ported | [Basic Pitch](https://github.com/spotify/basic-pitch) (Spotify), `basic_pitch` and `basic-pitch-ts` |

and ships this file. Model weights fetched at run time (Basic Pitch's, Apache-2.0, in Study 73) are not in the
repository and are not redistributed by Kairotic.
